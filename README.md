# Pizarra TV (Android TV APK)

Proyecto minimalista para compilar automaticamente el APK de `https://pizarra-tv.pages.dev/` usando GitHub Actions.

## Como compilar el APK
1. Sube todos los archivos de esta carpeta a la raiz de tu repositorio en GitHub.
2. Verifica que exista `.github/workflows/build.yml`.
3. Abre la pestana **Actions** en GitHub y espera 2-3 minutos.
4. Entra en la ejecucion completada (check verde) y descarga **PizarraTV-APK** en la seccion **Artifacts**.
5. Descomprime el archivo descargado para obtener `app-debug.apk` e instalalo en tu Android TV, Google TV o Fire TV.
